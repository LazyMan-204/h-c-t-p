# Ôn tập Python - Đề số 2

Bộ lời giải gồm 5 bài theo đề ôn tập Python trong ảnh.

## Danh sách bài
- `cau1.py`: Kiểm tra n trong [1, 99], tính tổng các ước và tính S = 1 + 2² + 3³ + ... + nⁿ.
- `cau2.py`: Đếm chữ thường, kiểm tra chuỗi đối xứng và viết hoa ký tự đầu mỗi từ.
- `cau3.py`: Nhập danh sách đến khi gặp 0, in các số dương chẵn và đếm số lần xuất hiện của k.
- `cau4.py`: Quản lý thông tin máy tính bằng từ điển, tìm và xóa máy tính theo số hiệu.
- `cau5.py`: Tạo lớp MonHoc, khởi tạo và hiển thị hai đối tượng mẫu.

## Cách chạy
Mở Terminal tại thư mục này và chạy từng chương trình:

```bash
python cau1.py
python cau2.py
python cau3.py
python cau4.py
python cau5.py
```

Mỗi câu là một file Python độc lập.
