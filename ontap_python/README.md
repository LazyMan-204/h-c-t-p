# Ôn tập Python

Bộ bài giải ôn tập theo đề thi Lập trình Python (5 câu).

## Danh sách bài

- `cau1.py`: Kiểm tra n trong [1, 1500], đếm chữ số lẻ và tính tổng S = 1/2 + 1/4 + ... + 1/(2n).
- `cau2.py`: Đếm chữ cái, kiểm tra chuỗi đối xứng và tính tổng chữ số.
- `cau3.py`: Nhập danh sách đến khi gặp 0, tính tổng số chẵn dương và đếm số lần xuất hiện của k.
- `cau4.py`: Quản lý sách bằng từ điển, tìm và xóa sách theo mã.
- `cau5.py`: Xây dựng lớp DienThoai và tạo hai đối tượng mẫu.

## Cách chạy

Mở Terminal tại thư mục này và chạy từng bài:

```bash
python cau1.py
python cau2.py
python cau3.py
python cau4.py
python cau5.py
```

Mỗi file là một chương trình độc lập, có chú thích tiếng Việt và kiểm tra dữ liệu nhập cơ bản.
